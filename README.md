# rag-playground

> 专注 RAG 相关实验，一个从零开始、逐步覆盖 RAG 各个环节的学习型项目。

个人 AI 学习实验仓库，monorepo 形式收纳多个学习性质的小项目。核心目的是理解 RAG(检索增强生成)、本地 LLM 工程实践等原理，而不是做成面向他人使用的产品。

## 项目列表

| 项目 | 状态 | 简介 |
|---|---|---|
| [rag-papers-qa](./rag-papers-qa) | 进行中 | 基于本地 Ollama + Chroma 的论文问答系统，用真实文献练手 RAG 全流程 |
| [character-chat](./character-chat) | 规划中 | 基于二次元设定的可对话模型 |

## 为什么是 monorepo

单人学习项目数量不多，拆成多个仓库反而增加管理成本。放在一起也方便日后整理成一套连贯的学习记录。

## 技术栈(会随项目增加更新)

- 本地推理：Ollama (`llama3`、`nomic-embed-text` 等)
- 向量库：Chroma
- 框架：LangChain
- 语言：Python

## 关于"教程化"

目前每个子项目的 README 里会记录踩坑过程和关键设计决策，作为轻量级的学习笔记。如果内容积累到一定程度，可能会整理进 `docs/` 目录做成更系统的教程或时间线，暂不强求一步做完整。

## 注意事项

- 各子项目下的原始数据文件(论文 PDF、向量库目录等)已通过 `.gitignore` 排除，不会提交到仓库。
- 任何 API key / 密钥不会硬编码在代码中。
