# 论文问答助手（paper-rag）

一个**完全在本地运行**的文献阅读助手：把 PDF 论文丢进去，就可以用中文直接提问、让它帮你归纳对比、生成综述段落。所有数据和模型都在你自己的电脑上，论文不会上传到任何服务器。

## 能做什么

- **论文问答**：针对一篇或多篇论文提问，回答附带原文出处片段，方便回查
- **综述写作**：选定若干论文，生成带引用的综述段落
- **多项目管理**：不同课题分开建库，互不干扰
- **增量建库**：新增或修改 PDF 后自动更新索引，不用从头重建
- **模型切换**：启动时自动检测本机 Ollama 已安装的模型，左侧下拉框随时切换

## 使用前提

本程序依赖 [Ollama](https://ollama.com) 在本机运行大模型，需要先装好它（只需一次）：

1. 到 https://ollama.com/download 下载并安装 Ollama（Windows）
2. 打开命令行（Win + R，输入 `cmd`，回车），执行：
   ```
   ollama pull llama3
   ollama pull nomic-embed-text
   ```
   第一个是对话模型（约 4.7 GB），第二个是向量模型（约 270 MB），下载时间取决于网速。
3. 保证 Ollama 在后台运行（安装后默认开机自启，任务栏有图标即可）

> 想要更好的中文效果，可以再从 [Ollama 模型库](https://ollama.com/library) 拉一个 Qwen 系列模型（例如 `ollama pull qwen3`），程序启动后会自动识别，在左侧下拉框切换即可。

**硬件建议**：16 GB 内存起步；有 NVIDIA 显卡（8 GB 显存以上）会快很多，纯 CPU 也能跑，只是慢一些。

## 下载与运行

### 方式一：直接用 exe（推荐，无需 Python）

1. 到 [Releases](https://github.com/yunhaibeidu/rag-playground/releases) 页面下载最新的 `.exe`
2. 放到一个单独的文件夹里（程序会在旁边生成 `data/` 目录存放索引）
3. 双击运行

第一次打开会有几秒钟的启动时间，属正常现象。Windows 可能提示"未知发布者"，点"更多信息 → 仍要运行"即可。

### 方式二：从源码运行

```bash
git clone https://github.com/yunhaibeidu/rag-playground.git
cd rag-playground
pip install -r requirements.txt
python paper-rag/exe版本/论文问答助手_PySide6版_已集成模型切换.py
```

## 基本流程

1. 启动后先**新建项目**（例如"XX课题"），一个项目对应一个文献库
2. 点击**添加论文**，选择 PDF 文件（可多选）
3. 等待建索引完成——**首次导入会比较慢**，每篇论文大约 10 秒到 1 分钟（取决于篇幅和电脑性能），后续只处理新增文件
4. 在输入框提问，或切换到写作模式生成综述

## 常见问题

**打开后提示连不上模型 / 模型列表为空**
Ollama 没在运行。在命令行执行 `ollama list`，能看到模型列表说明正常；看不到就重新启动 Ollama。

**回答速度很慢**
纯 CPU 推理本来就慢，llama3 8B 在 CPU 上每秒只有几个字。可以换参数量更小的模型（Ollama 模型库里带 `4b`、`3b` 后缀的），或者使用有独显的电脑。

**回答内容不准 / 答非所问**
试着把问题问得更具体，加上论文里出现过的关键词。也可以在界面里切换成中文能力更强的 Qwen 模型。

**扫描版 PDF 读不出内容**
目前只能提取文字层，扫描件（图片 PDF）需要先用 OCR 工具转成可复制文字的 PDF。

**想换电脑继续用**
把 exe 旁边的 `data/` 整个文件夹一起复制过去就行，索引会直接沿用。

## 技术栈

Ollama（llama3 / Qwen）+ nomic-embed-text 向量化 + Chroma 向量库 + BM25 混合检索 + LangChain 文本切分 + PySide6 界面。
